# Mikata v0.4.1-beta.1

This release displays the Mikata image logo prominently in the popup and removes the “logo idea” badge. It retains the **English / 日本語** switch to the popup, sidebar and dashboard. Preferences are saved per Chrome profile (extension) or website (dashboard). New checks request explanations in the selected language. Switching the UI does not start paid research; existing generated results, source titles, evidence quotes and Google attribution retain their original text. Use Check again for a fresh result in the other language. Existing accounts, service URLs, manual checks and allowances remain compatible.

Chrome extension for checking selected website claims with Gemini on Vertex AI and Google Search grounding. The factual assessment is separate from source-dependency and independence analysis.

## Install the submission

1. Download **mikata-extension-v0.4.1-beta.1.zip** from this release's Assets and unzip it. GitHub's automatic Source code archives contain developer defaults; use the attached extension ZIP for the hosted service.
2. Remove/disable any previous Mikata extension in this Chrome profile.
3. Open `chrome://extensions`, enable **Developer mode**, click **Load unpacked**, and select the unzipped folder containing `manifest.json`.
4. Open Mikata from Chrome's Extensions menu. Create a Mikata account, verify your email, and click **Refresh verified session**. Each Chrome profile signs in separately.
5. Refresh an ordinary article page, highlight a factual sentence (at least 12 characters), and click **Check with mikata**. The popup also accepts pasted claims.

No gcloud, Firebase CLI, cloud account, project ID, terminal or local server is required for release users. This is an unpacked beta, not a Chrome Web Store publication.

## Limits and interpretation

- Beta allowance: **100 research requests per verified account per UTC day, 100 total per UTC day** across all users. Reserved requests can count even if research fails. These request limits are not a dollar spending cap.
- Auto Scan has been removed. Research starts only when you explicitly check highlighted or pasted text, or submit an image through the dashboard. After updating, refresh existing article tabs to stop the old script.
- Selected text and page title (or an explicitly uploaded dashboard image) are processed by Google Cloud. Do not submit confidential content.
- Inaccessible pages remain unverified. A live final-revision astronomy check completed in 14.2 seconds but inspected zero pages because grounding redirects disallowed crawling and a publisher candidate timed out.
- Source independence remains a prototype with narrow positive coverage. Different domains, similar text, successful retrieval or model suggestions never establish independent evidence by themselves. Unknown relationships do not count as independent origins. A grounded factual verdict is not proof of independently verified sources.

## Validation

For this language-switching release, 73 backend tests, 30 extension tests, TypeScript/JavaScript checks and structural smoke checks passed. Controlled fixtures are mocked examples, not live verification. Live hosted tests confirmed real Gemini research, unsigned-request rejection, verified-email enforcement, direct client database denial, persistent quotas and quota rejection. Temporary test accounts were deleted without sending verification/reset emails.

Interactive Chrome installation and the real email-verification flow still require a manual test. Search availability, publisher access and model latency vary; the cloud service must remain enabled and funded for judges to use it.
