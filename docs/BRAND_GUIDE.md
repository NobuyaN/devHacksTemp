# Mikata brand proposal — for team review

**Brand name:** mikata / みかた — inspired by `味方` (ally) and `見方` (way of seeing/perspective). **Tone:** warm, curious, calm, educational, non-accusatory.

## What's included

- `design/original-sketch.png` — the team's original two hand-drawn logo sketches, preserved as provided.
- `design/logo-explorations/concept-a-clean-wordmark.png` — refined magnifying-glass M plus script lettering.
- `design/logo-explorations/concept-b-playful-exclamation.png` — expressive variant.
- `design/logo-explorations/concept-c-hand-and-magnifier.png` — variant incorporating a holding hand.
- `design/logo-explorations/concept-a-transparent.png` — approximate transparent cutout of Concept A.
- `extension/assets/brand/logo-candidate.png` — downsized draft for the toolbar popup (NOT final artwork).
- `design/logo-preview-on-paper.png` — quick paper-background preview.

## Current UI choice

The **popup displays Concept A** as a draft so collaborators can see it immediately. The browser-toolbar `icons/icon*.png` files still use the prior vector-style icon because the detailed sketch may lose legibility at 16 pixels. The sidebar likewise retains the old SVG icon until a design review.

## Ideas for a final pass — TODO(BRAND)

- Consider preserving slight hand jitter, but reduce distracting texture in the tiny icon.
- Develop a clean **M-in-magnifying-glass app icon** and a full **mikata wordmark** as separate assets. Export PNG at 16, 32, 48, 128px and test legibility.
- Use the following UI palette as a starting point: warm paper `#FBF9F3`; sage `#336952`; mint `#DFEEE2`; honey `#E9B764`; soft amber `#FFF0D9`; dusty rose `#F9E7E4`.
- Avoid aggressive language such as "FAKE NEWS!". Prefer "Needs context", "Worth a closer look", "Not enough evidence".
- Confirm which sketch and refinements are approved by their authors before publishing or adding to the project licensing/copyright worksheet. These draft variants are not automatically a trademark clearance or a production brand license.
